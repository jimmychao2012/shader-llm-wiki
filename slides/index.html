SHADER LAB · 管線 · 03/11

一個三角形怎麼出現在畫面上？

Graphics Pipeline 不等於只有 Shader。

頂點資料→Vertex Shader→圖元組裝／光柵化→Fragment Shader→測試／輸出

Fragment 是光柵化後待處理的片段，不一定會成為可見的 pixel。

SHADER LAB · 階段 · 04/11

Vertex 與 Fragment Shader 的分工

同一條管線中處理不同層次的資料。

Vertex Shader

逐頂點處理

計算 gl_Position 等輸出，並把頂點資料提供給後續階段。

Fragment Shader

逐片段處理

在光柵化之後，計算片段的顏色等輸出；還可能經過後續測試。

注意：Fragment Shader 執行次數不直接等於最終螢幕像素數。

SHADER LAB · GLSL · 05/11

用 GLSL 溝通資料

in 接收資料，out 輸出資料。

// Vertex Shader · GLSL 330 coreout vec3 vColor;
void main() {
  vColor = vec3(0.2, 0.8, 0.9);
  // 另需指定 gl_Position
}
// Fragment Shader · 示意片段in vec3 vColor;
out vec4 FragColor;
void main() {
  FragColor = vec4(vColor, 1.0);
}

這是分階段的教學片段，非可獨立編譯的完整 Shader。WebGL 1 的 attribute/varying 語法不能直接混入 GLSL 330 core。

SHADER LAB · 座標 · 06/11

為什麼要用矩陣變換？

把模型座標轉換成繪製所需的座標。

gl_Position = projection × view × model × vec4(position, 1.0)

Model

模型自身的縮放、旋轉與平移。

View / Projection

觀察位置與投影方式。

矩陣乘法一般不可交換，順序改變，結果也可能改變。

SHADER LAB · 顏色 · 08/11

mix() 如何產生漸層？

顏色可以視為 RGB 向量，依比例做線性插值。

mix(a, b, t) = (1 − t) × a + t × b

當 t = 0 取 a；t = 1 取 b；在 0 與 1 之間產生內插。畫面實際觀感仍受到色彩空間等影響。

SHADER LAB · 驗收 · 10/11

快速自我測驗

回答之前，先想一想是哪篇 Wiki 支持這個說法。

1. Fragment 一定會變成最終 Pixel 嗎？

不一定。Fragment 還可能受到測試與輸出階段影響。

2. 調整 uniform 需要重編 Shader 嗎？

一般不需要。由應用程式更新 uniform 的值即可。

3. model × view 與 view × model 一定相同嗎？

不一定。矩陣乘法通常不可交換。
